# 🔭 AstroVid: βίντεο αστροφυσικής από έγκριτες πηγές

Γράφεις ένα **θέμα** και μια **περιγραφή** και παίρνεις ένα ενημερωτικό βίντεο **2–5 λεπτών** με
αφήγηση στα ελληνικά (ή αγγλικά), υπότιτλους, εικόνες της NASA και πηγές στην οθόνη. Όλο το περιεχόμενο
βγαίνει από επιστημονική βιβλιογραφία.

## Πώς εξασφαλίζεται η επιστημονική εγκυρότητα

| Βήμα | Τι γίνεται |
|---|---|
| 0. Η απάντηση του Claude | Πρώτα κάνουμε στο Claude την ερώτησή σου ακριβώς όπως θα την έκανες σε μια συζήτηση. Η απάντησή του είναι η **βάση** του βίντεο: την εξήγηση, τη δομή και την έμφαση τις παίρνει το σενάριο από εκεί. Η απάντηση αποθηκεύεται στο `claude_answer.md`. |
| 1. Βιβλιογραφική αναζήτηση | Το Claude μετατρέπει το θέμα και τους ισχυρισμούς της απάντησης σε τεχνικά ερωτήματα και η εφαρμογή ψάχνει στο **OpenAlex** (peer-reviewed περιοδικά όπως ApJ, MNRAS, A&A, Nature, Science, και άρθρα ανασκόπησης), στο **NASA ADS** (προαιρετικά, μόνο refereed) και στο **arXiv** (astro-ph, gr-qc) για τα πιο πρόσφατα αποτελέσματα. Παίρνει πρόσφατες δημοσιεύσεις (τελευταία 6 χρόνια) και τις πιο πολυαναφερόμενες θεμελιώδεις εργασίες. |
| 2. Επαλήθευση & έρευνα | Κάθε βασικός ισχυρισμός της απάντησης χαρακτηρίζεται ως *επιβεβαιωμένος*, *χρειάζεται διόρθωση* ή *δεν βρέθηκε στις πηγές*, με παραπομπές. Με αναζήτηση στο web που επιτρέπεται **μόνο** σε NASA, ESA, ESO, NOIRLab, STScI, LIGO, IAU, AAS, ιστότοπους περιοδικών και στο **New Scientist** (σημειώνεται ως επιστημονική δημοσιογραφία, όχι peer-reviewed), επαληθεύει τις νεότερες τιμές (JWST, Euclid, DESI, LIGO κ.ά.). |
| 3. Σενάριο | Ακολουθεί την απάντηση του Claude με όλες τις διορθώσεις της επαλήθευσης. Συγκεκριμένα νούμερα ή πρόσφατα αποτελέσματα που δεν επαληθεύτηκαν αφαιρούνται. Ισχύουν οι κανόνες: όχι επινοημένα νούμερα, τιμές με αβεβαιότητες, διάκριση ανάμεσα σε consensus, ανοιχτή συζήτηση και υπόθεση, τα preprints σημειώνονται ως «χωρίς κρίση από ομότιμους», σωστή ελληνική ορολογία. |
| 4. Επιστημονικός έλεγχος | Δεύτερο, ανεξάρτητο πέρασμα που ελέγχει κάθε πρόταση με βάση τις πηγές, διορθώνει ή αφαιρεί ό,τι δεν τεκμηριώνεται και καταγράφει τις διορθώσεις. |
| 5. Διαφάνεια | Κάθε σκηνή δείχνει τις πηγές της στην οθόνη. Το βίντεο τελειώνει με κάρτα βιβλιογραφίας, και δίπλα στο βίντεο αποθηκεύονται το `sources.md` (πλήρεις αναφορές με DOI) και το `script.md`. |

> ⚠️ Η εφαρμογή μειώνει πολύ τον κίνδυνο λάθους, αλλά δεν τον μηδενίζει. Πριν δημοσιεύσεις ένα βίντεο,
> διάβασε το `script.md` και την καρτέλα «Επιστημονικός έλεγχος».

## Εγκατάσταση

Χρειάζεσαι Python 3.10+ και [ffmpeg](https://ffmpeg.org/download.html):
- macOS: `brew install ffmpeg`
- Ubuntu/Debian: `sudo apt install ffmpeg`
- Windows: `winget install ffmpeg`

```bash
python -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Ρύθμισε το κλειδί του Claude API (από το https://console.anthropic.com):

```bash
export ANTHROPIC_API_KEY="sk-ant-..."      # Windows PowerShell: $env:ANTHROPIC_API_KEY="sk-ant-..."
```

Προαιρετικά:

| Μεταβλητή | Χρήση |
|---|---|
| `ADS_API_TOKEN` | Δωρεάν token από το [NASA ADS](https://ui.adsabs.harvard.edu/user/settings/token). Προσθέτει τη μεγαλύτερη βάση refereed αστροφυσικής βιβλιογραφίας (συνιστάται). |
| `ASTROVID_CONTACT_EMAIL` | Email για το «polite pool» του OpenAlex, που δίνει ταχύτερες απαντήσεις. |
| `ASTROVID_MODEL` | Μοντέλο Claude (προεπιλογή `claude-opus-5-5`). |
| `ASTROVID_EFFORT` | `low` / `medium` / `high` (προεπιλογή) / `xhigh` / `max`. Ορίζει πόσο βαθιά σκέφτεται το μοντέλο. |
| `ASTROVID_OUTPUT` | Φάκελος εξόδου (προεπιλογή `output/`). |
| `ASTROVID_FONT`, `ASTROVID_FONT_BOLD` | Γραμματοσειρά με ελληνικούς χαρακτήρες, αν δεν βρεθεί αυτόματα. |

## Χρήση

### Web εφαρμογή

```bash
streamlit run app.py
```

Ανοίγει στο http://localhost:8501. Εκεί γράφεις θέμα και περιγραφή και διαλέγεις διάρκεια, φωνή και
μορφή (οριζόντιο ή κάθετο για Shorts/Reels). Μόλις τελειώσει, βλέπεις το βίντεο, το σενάριο, τις πηγές
και τις διορθώσεις του ελέγχου.

### Γραμμή εντολών

```bash
python -m astrovid "Η ένταση του Hubble" \
  -d "Γιατί διαφωνούν οι μετρήσεις του ρυθμού διαστολής; Τι δείχνουν JWST και DESI;" \
  -m 3
```

Επιλογές: `-l en` (αγγλικά), `--voice en-GB-RyanNeural`, `--list-voices`, `--aspect 9:16`, `--no-web`, `-o φάκελος`.

### Φωνές

- **Ελληνική αφήγηση**: Νέστορας, Αθηνά, και οι πολυγλωσσικές Andrew, Ava, Brian, Emma (μιλούν ελληνικά με αγγλική προφορά).
- **Αγγλική αφήγηση** (`-l en`): 13 φωνές από ΗΠΑ, Ηνωμένο Βασίλειο και Αυστραλία (Andrew, Ava, Brian, Emma, Christopher, Jenny, Guy, Aria, Ryan, Sonia, Thomas, Libby, Natasha) και οι πολυγλωσσικές.

Όλη η λίστα: `python -m astrovid --list-voices`.

## Δομή του κώδικα

```
astrovid/
├── research.py   # OpenAlex, NASA ADS, arXiv → λίστα πηγών με περιλήψεις
├── llm.py        # Claude: ερωτήματα, research brief (web search), σενάριο, fact-check
├── tts.py        # αφήγηση (Microsoft Edge neural voices) με χρονισμό υποτίτλων
├── visuals.py    # NASA Image Library, κάρτες τίτλου/βιβλιογραφίας, υπότιτλοι
├── render.py     # ffmpeg: Ken Burns, overlays, ήχος, ένωση σκηνών
├── pipeline.py   # η πλήρης ροή
└── cli.py
app.py            # Streamlit UI
tests/            # δοκιμές χωρίς δίκτυο (pytest)
```

## Σημειώσεις

- **Εικόνες**: προέρχονται από τη [NASA Image and Video Library](https://images.nasa.gov). Είναι
  γενικά public domain, αλλά ορισμένες εικόνες τρίτων (π.χ. ESA/Hubble) ζητούν αναφορά, που
  εμφανίζεται στην οθόνη και στο `image_credits.md`. Αν δεν βρεθεί κατάλληλη εικόνα, χρησιμοποιείται
  συνθετικό έναστρο φόντο που σημειώνεται ως «Ψηφιακή απεικόνιση».
- **Φωνή**: η σύνθεση φωνής (edge-tts) χρειάζεται σύνδεση στο internet.
- **Κόστος**: κάθε βίντεο κάνει 5 κλήσεις στο Claude API (με έως 8 αναζητήσεις web).
- **Δοκιμές**: `pip install pytest && pytest`. Τρέχουν όλη τη ροή με ψεύτικο LLM και σιωπηλή
  αφήγηση, και κάνουν πραγματικό μοντάζ με ffmpeg.
